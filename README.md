# 3D-Экшон: Суть Такова 🎮

Легендарная игра, воплощенная в 3D на WebGL (Three.js).

## Особенности
* **3 фракции**: Лесные эльфы, Охрана дворца, Злодей.
* **Грабеж корованов**: торговые караваны движутся по центральному тракту.
* **4 зоны**: Нейтральные земли людей, Императорский дворец, Эльфийский лес, Форт злодея в горах.
* **LOD-деревья**: вдали деревья картинкой (2D), вблизи честные 3D-модели.
* **Травмы и протезы (Daggerfall)**: потеря глаза (слепота полуэкрана), потеря руки (кровотечение), потеря ноги (ползание), протезы и коляски.
* **3D-трупы** и быстрые сохранения (F5 / F9).

## Как запустить
Просто откройте `index.html` в браузере или запустите `start_game.bat`.
